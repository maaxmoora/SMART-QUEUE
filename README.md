# SMART-QUEUE
SmartQueue - Sistema de Gestión de Turnos
Descripción del Proyecto
SmartQueue es una aplicación de escritorio desarrollada en Java que digitaliza la gestión de turnos en establecimientos comerciales, centros médicos y servicios públicos. El sistema asigna números de turno automáticamente, gestiona colas de espera y notifica a los usuarios cuando son llamados.

Objetivos Principales
Reducir tiempos de espera en establecimientos

Digitalizar la gestión de colas tradicionales

Mejorar la organización y eficiencia operativa

Implementar correctamente principios POO y arquitectura MVC

Características
Funcionalidades Principales
Solicitud de turnos: Los usuarios pueden solicitar turnos seleccionando entre diferentes servicios

Gestión inteligente de colas: Sistema FIFO (First-In, First-Out) automatizado

Notificaciones: Aviso cuando un turno es llamado

Visualización en tiempo real: Estado actual de la cola de espera

Gestión de servicios múltiples: Diferentes tipos de servicio con tiempos estimados

Validación de entradas: Control de errores y validación de datos de usuario

Tecnologías y Paradigmas
Lenguaje: Java 17

Paradigma: Programación Orientada a Objetos (POO)

Arquitectura: Modelo-Vista-Controlador (MVC)

Control de versiones: Git con GitHub

Documentación: UML completo
